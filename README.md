# Otter_Population_Modeling_Drohan
Contains the final write up for an applied math modeling project on Californian Sea Otter Populations. Work is done by Eli Drohan and team members.

Sea Otter Populations in California have been on a steady increase. However, their populations have yet to breach into Northern California (specifically San Francisco Bay, Drakes Estero, and Tomales Bay). This is partially due to juvenile shark predation on Sea Otters. To gain insight in the shark-otter population dynamics, we modeled their populations using coupled differential equations. Our models showed shark predation had a significant impact on otter populations.

Lotka-Voltera Coupled ODE's were used to model the populations. Numerical methods implemented in matlab were then used to model the ODE's. Graphs on the model itself, along with demonstrations and approximation of a bifurcation in relation to the shark predation coefficient are shown.
